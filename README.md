# 吞噬者背包 / Devourer Pack

一个饥荒联机版 (Don't Starve Together) 的成长型背包模组。通过吞噬物品来解锁各种能力，逐步从普通背包进化为多功能神器。

## 特性

### 吞噬进化系统
- 吞噬指定物品提升背包等级（Lv1 → Lv2 → Lv3），每级解锁更多格子与效果槽
- **给金子** → 显示升级所需材料 + 随机推荐可吞噬物品
- **给月岩** → 展示当前已解锁的所有能力
- 超过 80+ 种可吞噬物品，涵盖装备、Boss 掉落、材料、食物等

### 控制面板
- 按 **F7** 打开控制面板，可视化管理所有功能开关（14 个控制项）
- 按 **F8** 切换当前绑定的功能，按 **F9** 执行
- 支持快捷键循环切换所有控制功能
- 所有控制开关状态持久化保存

### 属性效果（80+ 项可开关）
| 类别 | 效果示例 |
|------|---------|
| 防御 | 伤害减免（最高 95%）、位面防御、骨甲免伤 |
| 战斗 | 额外伤害、位面伤害、百分比血量伤害、吸血、电击 |
| 反伤 | 物理反射、位面反射、AOE 反射、生命值反射 |
| 环境 | 保暖、隔热、发光、夜视、防雨、防酸雨、防风沙 |
| 移动 | 踏水、虚空行走、如履平地、踏雪无痕、加速 |
| 生存 | 生命恢复、理智恢复、复活、冰冻抗性、昏睡抗性 |
| 功能 | 无限堆叠、加热/制冷格子、自动修理、弹性空间 |
| 伪装 | 蜘蛛伪装、兔人恐惧、兔子伪装、牛牛伪装、狗狗朋友 |
| 特殊 | 幸运值、暗影等级、月灵助攻、启迪/暗影模式 |

### 套装系统（7 套）
集齐指定装备激活套装效果：
- **四季之灵** — 保温/隔热翻倍
- **暗影之力** — 暗影生物增伤 + 范围伤害
- **亮茄套装** — 暗影敌对增伤
- **绝望石套装** — 月亮敌对增伤
- **霸者神威**（铥矿） — 免疫攻击僵直 + 黑血恢复
- **公主与骑士** — 幸运翻倍 + 移速 +5% + 减伤 +5%
- **泰拉瑞亚联动** — 减缓饥饿 20%
- **蜗牛之盾** — 额外减伤 5%
- **强握** — 武器不脱手
- **快速制作** — 制作速度提升
- **修理小能手** — 修理效率翻倍

### 猪人守护
- 吞噬 **猪鼻铸币** 召唤一只猪人随从
- 猪人拥有独立等级系统，通过击杀怪物获取经验成长
- 升级提升：攻击力、位面攻击/防御、移速、攻击范围、连击数、吸血、范围伤害、冰冻抗性、体型
- Boss 等级突破机制：击杀指定种类 Boss 才能突破等级上限
- 可给猪人装备头盔、喂食
- 猪人死亡后名字和外观**永久保留**，消耗新铸币即可复活
- 68 个随机搞笑名字

## 按键默认配置
| 按键 | 功能 |
|------|------|
| F7 | 打开控制面板 |
| F8 | 切换当前绑定功能 |
| F9 | 执行当前绑定功能 |

## 配置选项
模组提供 60+ 个配置项，每个效果可独立开关：
- 背包初始等级 / 初始格子行数
- 最大防御、移速、视野上限
- 食物吞噬上限
- 猪人体型上限
- 所有 80+ 项效果的独立开关
- 背包说话频率
- 猪王修改（猪王年掉铸币 + 兼容永不妥协）
- 背包科技（吞噬解锁制作站科技）

## 制作
容器制作栏，**无需科技**，使用基础材料即可制作。

## 兼容性
- 饥荒联机版 API 版本 10
- 所有客户端需安装
- 兼容「永不妥协」(Uncompromising Mode) 猪王年 Bug 修复
- 可配置关闭任意效果以兼容其他模组
